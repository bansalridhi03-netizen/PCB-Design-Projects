# LibrePCB Projects

This folder contains my personal electronics and printed circuit board design projects created using LibrePCB.

## Areas of Work

- Electronic circuit schematic capture
- PCB layout and board design
- Electronic component placement
- Circuit routing and connectivity
- Component libraries, symbols, and footprints
- PCB design visualisation and documentation

## Software

**LibrePCB**

## Project Files

Individual project folders may contain:
- Original LibrePCB project files
- Electronic circuit schematics
- PCB layouts and board designs
- 2D and 3D design screenshots
- Project descriptions and design notes
- Exported fabrication files, where available

## Purpose

These projects demonstrate my exploration of schematic design, PCB layout, and electronic design workflows using LibrePCB.
